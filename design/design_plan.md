# Design Plan — [ПРОДУКТ] (учебная система для старшеклассников)

Документ фиксирует уже принятые дизайн-решения для передачи в Claude Design на построение интерактивных экранов. Это не план на будущее, а запись того, что уже утверждено.

---

## 1. Концепция и обоснование

**Название концепции:** Индиго и графит.

**Mood:** холодный, технологичный, сдержанный. Тёмная тема по умолчанию. Ощущение серьёзного взрослого инструмента — ближе к Linear и Arc, чем к консьюмерским AI-ассистентам или мессенджерам.

**Почему так:** продукт позиционируется для аудитории 14–18 лет, но сознательно избегает "яркого приложения для школьников" — это прямой принцип из продуктовой документации. В процессе работы разбирались референсы (Gemini, Telegram, DeepSeek) — из них забраны только структурные и геометрические паттерны (сегментированные переключатели, капсульная навигация, контекстные панели), но не их цветовой язык: разноцветные иконки-плашки и радужные градиенты сознательно отклонены как противоречащие принципу сдержанности.

**Референсы геометрии (что взято):**
- Сегментированный pill-переключатель режимов — по образцу DeepSeek (не залитые цветом блоки, а приглушённая подсветка активного варианта).
- Капсульная навигация снизу с "liquid glass" эффектом (полупрозрачный фон, мягкое свечение по краю) и расширяющимся активным пунктом с подписью — по образцу нового Telegram для Android.
- Иконки вместо текстовых лейблов на вложенных вкладках (везде, где сегментов больше одного) — для визуальной лёгкости.

## 3. Типографика

| Роль | Шрифт | Размер | Начертание |
|---|---|---|---|
| Заголовки экранов (h1-уровень) | Space Grotesk | 18–20px | Medium (500) |
| Заголовки внутри рабочей зоны сессии | Space Grotesk | 17px | Medium (500) |
| Основной текст / значения | Inter | 12–15px | Regular (400) / Medium для акцентных значений |
| Вторичный текст / подписи | Inter | 10–11px | Regular (400) |
| Метки секций (uppercase лейблы) | Inter | 9–10px | Medium, letter-spacing ~0.05em |

Никакого serif — весь интерфейс sans-serif, включая рабочую зону сессии (не редакторский контент, чистый UI).

## 4. Геометрия

| Элемент | Радиус | Комментарий |
|---|---|---|
| Таббар (капсула-контейнер) | 32px | Максимальный радиус в системе — ориентир для остальных |
| Кнопки нижней навигации (nav-item) | 24px | Активный пункт растягивается (flex-grow) и показывает подпись |
| Основные кнопки действия (primary/secondary) | 22–26px | "Продолжить обучение", "Создать проект", "Дальше" |
| Карточки (проекты, техники, материалы) | 20–24px | Единый радиус для всех карточек |
| Баннеры-уведомления | 20–24px | Стакаются: второй баннер уменьшен (scale ~0.97) и полупрозрачен |
| Сегментированные переключатели (контейнер) | 24–30px | Внутренние сегменты — на 4–6px меньше контейнера |
| Плитки (материалы, вложения) | 20–24px | Квадратные пропорции, иконка + подпись |
| Поля форм / инпуты | 18–20px | |
| Выпадающие меню ("•••") | 16px | Компактнее основных карточек |

**Принцип:** вся геометрия скруглённая и единообразная, никаких острых/квадратных углов. Радиус нарастает вместе с "весом" элемента (контейнеры крупнее — радиус больше).

**Иконки:** только монохромные (в акцентном оттенке `#8B8FFA` / `#A5A9FF` на тёмном фоне), без цветных плашек-иконок разного цвета на одном экране (сознательно отклонено как консьюмерский паттерн).

## 5. Структура навигации

**Таббар — 4 пункта, слева направо:**
1. Главная (иконка home) — первая слева
2. Проекты (иконка folder)
3. О тебе (иконка chart-bar)
4. Профиль (иконка user)

Активный пункт: заливка акцентом `#6366F1`, расширяется (flex-grow), показывает иконку + подпись белым текстом. Неактивные пункты — только иконка, приглушённый цвет.

**Таббар присутствует на всех основных экранах**, включая "Профиль проекта" (доступ к нему не должен убирать нижнюю навигацию). Исключение — рабочая зона сессии (модальное полноэкранное состояние, вне основной навигации, таббара нет).

## 6. Экраны

### 6.1 Главная

**Структура сверху вниз:**
1. Статус-бар (время, индикатор сети)
2. Стек баннеров-уведомлений (0–2 шт видно одновременно): стиль push-уведомлений iOS lock screen. Первый — полный вид, второй под ним — уменьшен и приглушён. Автоматически исчезают через 5–6 секунд или свайпаются вверх. Клик — переход на профиль соответствующего долгого проекта.
3. Центральный блок:
   - Заголовок-вопрос: "Что разбираем?" (режим "Разобрать тему") / "К чему готовимся?" (режим "Готовиться к большому") — текст меняется в зависимости от выбранного сегмента.
   - **Сегментированный переключатель** (2 варианта, иконка + подпись в каждом): "Разобрать тему" (иконка молнии) / "Готовиться к большому" (иконка мишени). Не залитые цветом блоки — приглушённая подсветка активного варианта (фон `#262C4A`, рамка `#4A50A8`).
   - **Контекстная панель под переключателем — меняется по выбранному сегменту:**
     - Режим "Разобрать тему": лейбл "Принеси материал для разбора" + ряд из 3 плиток (Текст / Фото / Ссылка), каждая — иконка + подпись.
     - Режим "Готовиться к большому": мини-форма — поле "Название проекта" (текстовый инпут с плейсхолдером), два поля в ряд ("Предмет" — выбор, "Дедлайн" — выбор даты), кнопка "Создать проект" (акцентная заливка).
4. Таббар снизу (Главная активна).

**Поведение:** переключение сегмента должно анимированно/визуально менять контекстную панель под ним (не просто подсветку — реальную смену контента).

### 6.2 Проекты

**Структура:**
1. Заголовок "Проекты" + круглая кнопка сортировки в углу (иконка adjustments) — открывает выбор критерия: по дедлайну / по количеству материалов / по прогрессу.
2. **Вкладки — иконки, не текст:** иконка папки = "Активные" (по умолчанию), иконка истории/часов = "История". Тот же визуальный паттерн сегментированного контрола, что и на Главной, но как таб-навигация между двумя списками.
3. **Подраздел "Активные" (список карточек проектов):**
   - Каждая карточка: название, счётчик материалов (справа сверху), теги (предмет, дедлайн если есть), трёхцветная шкала прогресса + текстовая легенда с процентами (Закреплено / Изучаем / Впереди).
   - Пиннутый (приоритетный) проект: акцентная рамка (`#4A50A8`) + иконка pin рядом с названием. Всегда отображается первым независимо от выбранной сортировки — как закреплённые чаты в Telegram.
4. **Подраздел "История" (короткие сессии):** хронологический список, свежие сверху. Каждая запись — заголовок темы, дата, превью материалов. Действия: Открыть / Пройти снова / Добавить материалы (система предлагает конвертацию в долгий проект) / Удалить.
5. Таббар снизу (Проекты активны).

### 6.3 О тебе

**Структура:**
1. Заголовок "О тебе".
2. **Вкладки — 3 иконки** (тот же паттерн, что в Проектах): график (Статистика) / мишень (Мои методы) / глаз (Наблюдения). Без текстовых подписей на самих вкладках.
3. **Вкладка "Статистика":**
   - Живой текстовый блок сверху — 2–3 предложения человеческим языком о самочувствии продукта за неделю (не сухие цифры).
   - Сетка 2×2 из 4 показателей простыми числами (часы за неделю, количество разборов, число проектов, % завершения).
   - Тепловая карта активности за месяц (сетка ячеек, 4 уровня интенсивности).
4. **Вкладка "Мои методы":**
   - Блок "Текущие приоритеты" — список техник с мини-прогресс-барами (визуализация текущего приоритета системы), редактируется вручную.
   - Кнопка "Реестр техник" снизу — переход в отдельный экран.
5. **Вкладка "Наблюдения":**
   - Хронологическая лента карточек: дата + текст наблюдения. Партнёрский, не оценивающий тон ("я заметил, что...", а не "ты плохо справляешься с...").
6. Таббар снизу (О тебе активен).

### 6.4 Реестр техник

**Структура:**
1. Заголовок + кнопка "назад".
2. Сетка карточек 2 колонки.
3. **Демо-карточки (4 шт для хакатона, полностью расписаны):** акцентная рамка (`#4A50A8`), иконка, название техники человеко-понятным языком, короткое описание, тег (предмет/контекст применения), ссылка "Попробовать →" (ведёт на интерактивное тестовое задание).
4. **Карточки-заглушки (остальные из 15–20 техник полного реестра):** только иконка + название, приглушённая непрозрачность, без описания — задел на будущее наполнение.

Экран доступен только из "Мои методы", пользователь не видит его по умолчанию.

### 6.5 Профиль

**Структура:**
1. Заголовок "Профиль".
2. Список настроек, сгруппированный по секциям (лейбл секции — uppercase, приглушённый):
   - **Аккаунт:** Аккаунт (email, подписка, привязки Apple/Google, удаление аккаунта).
   - **Учёба:** Занятия (время сессий по умолчанию, длина, дни без работы), Фокус-режим (список блокируемых приложений/уведомлений на время сессии).
   - **Данные и вид:** Приватность (экспорт данных, использование ответов для обучения моделей — по умолчанию выключено), Внешний вид (тема, размер шрифта, язык интерфейса).
   - **Помощь:** Помощь (FAQ, обратная связь, короткие объяснения науки обучения).
3. Каждая строка: круглая иконка (монохромная, акцентный тон) + заголовок + короткое пояснение под ним + шеврон справа.
4. Таббар снизу (Профиль активен).

### 6.6 Профиль проекта

Отдельный экран вне таббара по логике перехода, но **таббар остаётся видимым** (подсвечен пункт "Проекты", откуда пришёл переход).

**Структура:**
1. Заголовок: кнопка "назад" слева, кнопка "•••" справа.
2. **Кнопка "•••" открывает выпадающее меню** (не отдельный ряд кнопок на месте таббара!): Изменить дедлайн / Приостановить / Поставить приоритет / Удалить проект (последний пункт — предупреждающий цвет `#E88888`).
3. Название проекта + мета-строка (тема, дедлайн).
4. Крупная трёхцветная шкала прогресса + легенда с процентами.
5. Секция "Материалы (N)": список материалов (иконка типа + название) + действие "Добавить материал".
6. Блок расписания: "Осталось сессий" / "Следующая сессия" (дата, время).
7. Кнопка "Продолжить обучение" (акцентная, primary) — над таббаром, не на его месте.
8. Таббар снизу.

### 6.7 Рабочая зона сессии

Модальное полноэкранное состояние, **не часть основной навигации — таббара нет**.

**Структура:**
1. Статус-бар.
2. Крестик закрытия (справа сверху).
3. Тонкая полоса прогресса сессии (акцентная заливка).
4. Центр экрана: вопрос или объяснение (крупный текст, без подписи названия техники — техники никогда не именуются пользователю).
5. Ниже — либо поле ответа (текстовый инпут с плейсхолдером "Напиши ответ здесь..."), либо (в других типах шагов) одна кнопка "Дальше".
6. Никаких боковых меню, никаких плавающих кнопок — одно действие на экране.

**Фон — базовый `#14161C`, тот же, что у всего приложения** (не затемнённый отдельно).

## 8. Ключевые принципы поведения (для Claude Design — не терять при вёрстке)

- **Никакой геймификации** — без стриков, очков, бейджей, лидербордов.
- **Прогресс — только реальный результат**, не сложные графики и не проценты ради процентов (кроме трёхцветной шкалы — она осознанно простая).
- **Имена техник обучения не показываются пользователю** в рабочей зоне сессии и на Главной. Видны только в разделе "О тебе" → "Мои методы" и в "Реестре техник", куда пользователь заходит осознанно.
- **Партнёрский, не оценивающий тон** в разделе "Наблюдения обо мне".
- **Автономия** — все настройки, которые система "решила" за пользователя, редактируемы (приоритеты техник, дедлайны, конфигурация).
- **Таббар присутствует всегда**, кроме модального состояния рабочей зоны сессии. Второстепенные действия экрана никогда не занимают его место — уходят в выпадающие меню.
- **Единая скруглённая геометрия** без исключений — если новый элемент не описан выше, брать ближайший по "весу" радиус из таблицы в разделе 4.

## 9. Что не входит в этот макет (out of scope)

- Экраны онбординга (волна 1, волна 2) — не проработаны в этом заходе.
- Точные тексты/копирайтинг всех экранов (кроме уже показанных примеров) — заголовки, пустые состояния, ошибки.
